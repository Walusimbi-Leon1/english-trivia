# English Trivia 📚

Fast-paced multiplayer **English phrase trivia** for Discord Activities — idioms, proverbs, colloquialisms, jargon, euphemisms, maxims & aphorisms, and clichés.

- **One global room** — every player sees the same question at the same time (20s per question, clock runs 24/7)
- **Speed-based scoring** — first correct answer in a slot scores highest
- **Persistent players** — your score and rank survive leaving and coming back
- **Playable in Discord** (Activity) or directly in a browser (guest mode)

Live: https://english-trivia.walusimbileon1.workers.dev

## Architecture (Trivia Rumble Elite / Quran Trivia pattern)

Single Cloudflare Worker serves the whole game: static assets, Discord OAuth exchange (`/api/exchange`), and same-origin Firebase proxies (`/firebase/*` REST + `/firebase/stream/*` SSE). All state lives in a shared public-writable Firebase Realtime Database under the `english/global` namespace:

```
english/global/game     = { questionStart, slotDuration, bankLen, startedAt }
english/global/bank/<i> = { question, options, correctAnswer, ref? }
english/global/players/<uid> = { id, username, avatarUrl, score, lastSeen, online }  (persistent)
english/global/answers/<slot>/<uid> = { answer, at }
english/global/meta     = { generating, used: [...] }
```

The current question is computed deterministically by every client:

```
slot = floor((now - questionStart) / slotDuration)
question = bank[slot % bank.length]
```

## Phrase corpus (`data/`)

The source material for all questions — arrays of `{"p": "<phrase>", "m": "<meaning>"}`:

| File | Category | Status |
|---|---|---|
| `data/idioms.json` | Idioms | ✅ curated |
| `data/proverbs.json` | Proverbs | ✅ curated |
| `data/colloquialisms.json` | Colloquialisms | ⏳ GitHub Actions |
| `data/jargon.json` | Jargon | ⏳ GitHub Actions |
| `data/euphemisms.json` | Euphemisms | ⏳ GitHub Actions |
| `data/maxims-aphorisms.json` | Maxims & Aphorisms | ⏳ GitHub Actions |
| `data/cliches.json` | Clichés | ⏳ GitHub Actions |

**Idioms + proverbs were curated by hand.** The remaining five categories are generated by the `generate-phrases` workflow (`.github/workflows/generate-phrases.yml`) using opencode.ai (big-pickle) from **GitHub runners** — fresh IPs, so opencode.ai can't rate-limit or flag the machine that runs the game (Cloudflare Workers egress is blocked by opencode.ai with error 1042, and the EC2 dev machine's IP was previously flagged).

The workflow runs daily (03:23 UTC) and on manual dispatch; it writes any missing/short category files and commits them back via a PR (main is branch-protected).

## Question pipeline (GitHub Actions)

`.github/workflows/generate-questions.yml` runs **every 30 minutes**:

1. Samples random phrases from `data/*.json`
2. Asks opencode.ai big-pickle to write fresh 4-option questions from them (40 per chunk, 24k token budget)
3. Writes them into the Firebase bank under `english/global`

Bank math: the game drains ~180 questions/hour → the pipeline keeps ~2 hours of runway. `scripts/generate-questions.js` supports APPEND (healthy bank) and RESET (bank exhausted/behind — rebuilds instantly) modes.

The worker also embeds a **deterministic fallback bank** (built at deploy time from `data/*.json` by `build.js` — "What does the phrase X mean?" with 3 distractor meanings) so the game can never stall, even if the pipeline is down.

## Deploy

```bash
CF_API_TOKEN=<token> \
DISCORD_CLIENT_ID=<client id> \
DISCORD_CLIENT_SECRET=<secret> \
bash deploy.sh
```

- `deploy.sh` builds `dist/worker.js`, uploads via the Cloudflare API (multipart PUT with `compatibility_date` in metadata), enables the workers.dev subdomain, and stores `DISCORD_CLIENT_SECRET` as an encrypted worker secret (never in the repo).
- Redirect URI: `https://english-trivia.walusimbileon1.workers.dev` (register exactly, no trailing slash).
- `OPENCODE_API_KEY` is optional for the worker (the Actions pipeline uses the repo secret) but can be passed to deploy.sh for the worker-side generation fallback.
